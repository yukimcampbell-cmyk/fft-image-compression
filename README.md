# Image Compression Using Fourier Transforms
A MATLAB project implementing block-based image compression using 2D Fourier transforms. The image is divided into 15×15 blocks, transformed into the frequency domain, and Fourier coefficients below a specified threshold are removed. The compressed image is then reconstructed using the inverse Fourier transform.
The project demonstrates the trade-off between compression rate and image quality by comparing images compressed to approximately 50%, 80%, and 95%.
